# Sample documents

Drop public financial documents here for ingestion (Phase 2):

- 10-K / 10-Q filings (SEC EDGAR)
- Annual reports
- Earnings call transcripts
- Investor presentations

**Only use public / legally reusable material.** This project does not use
proprietary data. PDFs are gitignored (see `.gitignore`); commit small `.txt`
samples if you want a reproducible demo corpus.

A tiny text sample (`apple_services_sample.txt`) is included so the ingestion
script and chunker can be exercised immediately.
